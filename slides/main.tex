\section{Problem}

\begin{frame}{What is my thesis about?}
    M \ldots Molecular structure \quad
    S \ldots Mass spectrum
    \begin{itemize}
%      \item \textbf{Computational mass spectrometry} with a focus on \textbf{MS spectrum modeling}
        \item Formulated mathematically as a function:
            \[
                f : M \to S
            \]
        \item Investigation of the \textbf{inverse problem}:
            \[
                f^{-1} : S \to M
            \]
        \item Integration of \textbf{chemically studied reaction rules} modeled in \textbf{M\O D}
        \item Use of fragmentation trees to support traditional machine-learning-based MS models
    \end{itemize}
\end{frame}
\note{
    What is this project about?

    formulated as mathematically as a function mapping molecular structure to mass spectrum, 

    and the inverse problem of mapping mass spectrum to molecular structure.

    Here we integrate the relationship between the fragments, 

    which are modeled in M\O D which then are used to enhance ML models
}

\note{
    Why would we want to do MS modeling? What is the motivation?

    Mass spectrometry is one of the most widely used tools for molecular analysis

    As interpreting MS data remains largely expert-driven and time-consuming

    the high-through-put in data acquisition does

    not get translated through to data analysis, we have a bottleneck.

    Also, through incorporating chemical structure, 
    we can enhance machine learning models, in terms of interpretability and generalization
}

    A hydrocarbon substituent is only containing C-H bonds.

	Here I collects in a breadth-first manner all neighbors

\begin{frame}{M\O D - Predicate - Heteroatom Group}

    }
\end{frame}
\note{
    A valid heteroatom groups must contain at least one non-C/H atom in its neighbors

    Here I collect in a breadth-first manner all neighbors

    that are not matched by the original rule and 

    checks if the resulting set is not disjoint with \{H, C\}
}
